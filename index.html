എന്താണ് MSTC Blockchain?

Understanding MST Blockchain from the beginning

MST Blockchain

MST Blockchain is presented by its official materials as a public, EVM-compatible Layer 1 blockchain developed by Masterstroke Technosoft.


Layer 1 എന്നത് സ്വന്തം blockchain network, സ്വന്തം consensus mechanism, validators, blocks, transactions, native asset എന്നിവയുള്ള അടിസ്ഥാന blockchain infrastructure എന്നാണ് അർത്ഥമാക്കുന്നത്.


MSTC ആണ് MST ecosystem-ൽ ഉപയോഗിക്കുന്ന native digital asset. Network transactions, validator participation, applications തുടങ്ങിയ ecosystem activities-ൽ MSTC ഉപയോഗിക്കാം.

ലളിതമായി പറഞ്ഞാൽ

  • Blockchain = decentralized digital ledger
  • Layer 1 = സ്വന്തം blockchain network
  • Block = transactions അടങ്ങിയ ഒരു record
  • Validator = transactions/network security സഹായിക്കുന്ന participant
  • Consensus = network agreement സംവിധാനം
  • Smart Contract = blockchain-ൽ പ്രവർത്തിക്കുന്ന programmable code
  • DApp = blockchain ഉപയോഗിക്കുന്ന application
  • MSTC = MST network-ന്റെ native asset

MST Blockchain എങ്ങനെ പ്രവർത്തിക്കുന്നു?

Transaction മുതൽ blockchain record വരെ

1

User Transaction

ഒരു user wallet ഉപയോഗിച്ച് transaction അല്ലെങ്കിൽ smart-contract interaction ആരംഭിക്കുന്നു.

2

Network

Transaction network-ലേക്ക് broadcast ചെയ്യപ്പെടുന്നു.

3

Validation

Validators consensus mechanism അനുസരിച്ച് transactions process/validate ചെയ്യുന്നതിൽ പങ്കെടുക്കുന്നു.

4

Block

Validated transactions blockchain blocks-ൽ record ചെയ്യപ്പെടുന്നു.

5

Final Record

On-chain data explorer വഴി verify ചെയ്യാൻ കഴിയുന്ന public blockchain record ആയി മാറുന്നു.
